# P-CAD: схемы скриптами

Корень набора — папка этого файла (клон `RungeKut/Pcad-Skill`). Библиотека
`pkit`, x86-хост `tools/dbx-host`, база `knowledge/` (карта и поиск по
симптому — `INDEX.md`). Общие правила — соседний скилл skill-skill.

**Первым делом:** `git -C <корень> pull --rebase`. Зависимости и сборка
`DbxHost.exe` — 40-01.

```python
import sys; sys.path.insert(0, r"<корень>")
import pkit as pk
pk.utf8_console()                     # иначе print с кириллицей упадёт
s = pk.dump(r"D:\проект\схема.SCH")   # копия; оригинал не трогается
print(s, s.bom(), s.pin_nets())       # {(refdes, pindes): netname}
```

Схема открыта человеком в Sch.exe — `pk.dump_live()` (только чтение).
Режимы, рабочий цикл, единицы — 20-02; DBX — DDE-клиент к запущенному
редактору, файлов сам не читает — 10-01.

## Железные правила

1. Только над копией в папке без пробелов и кириллицы — `pkit` копирует
   сам (20-01, 30-02).
2. Пакетный режим — только когда Sch.exe не запущен; редактор открыт
   человеком — `dump_live` или просить закрыть (30-03).
3. Оригинал не перезаписывается: результат — `export_saved(новый_путь)`;
   в живом режиме `save` запрещён (20-01, 30-04).
4. Проверять числом из независимого источника: «0 компонентов» — не
   правда: чужой экземпляр (30-03) или файл ещё не догрузился (30-06).
5. Непроверенное не выдавать за проверенное — ни в коде, ни в отчёте, ни в
   базе.
