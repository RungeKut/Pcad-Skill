# Пакетный и живой режим

## Что происходит

`Dbx32.dll` — DDE-клиент к **запущенному** редактору (10-01), поэтому к
схеме два пути:

| Путь | Когда | Чем |
|---|---|---|
| **пакетный** | чтение или правка файла .SCH; Sch.exe не запущен | `pk.dump(path)`, `pk.open_design(path)` |
| **живой** | человек держит схему открытой в Sch.exe | `pk.dump_live()`, `pk.open_live()` — только чтение |

Пакетный режим сам копирует схему в папку задания (20-01), запускает
`Sch.exe <копия>`, выгружает и гасит **свой** редактор по PID. Живой
подключается к открытому редактору и ничего в нём не сохраняет и не
закрывает (30-04).

## Как правильно

```python
import sys; sys.path.insert(0, r"<корень набора>")
import pkit as pk

pk.utf8_console()                     # иначе print с кириллицей упадёт
print(pk.pcad_root())                 # где найден P-CAD (40-01)

s = pk.dump(r"D:\проект\схема.SCH")   # копия, оригинал не трогается
print(s)                              # компоненты, цепи
for refdes in s.refdes():
    c = s.comp(refdes)
    print(refdes, c.type, c.value, c.attrs.get("ПЭ3", ""))
print(s.pin_nets())                   # {(refdes, pindes): netname}
print(s.bom())                        # {(type, value): [refdes...]}
```

Sch.exe уже запущен — `pk.dump_live()` вместо `pk.dump()`; пакетный режим
в этом случае сам отказывает (30-03).

Координаты в сырых данных — database units: 100000 на мм
(`pk.sch.DB_PER_MM`), 2540 на mil; перевод — `pk.Schematic.to_mm(v)`,
`to_mil(v)`.

После выгрузки сверять количества компонентов и цепей с ожиданием из
независимого источника (отчёт редактора, прошлая выгрузка):
`TGetFirst*` на чужом экземпляре молча даёт пустоту (30-03).

## Как неправильно

* Запускать пакетный режим при открытом человеком Sch.exe — выгрузка
  придёт из чужого дизайна (30-03).
* Сохранять в живом режиме — перезапишет открытый у человека файл (30-04).
* Верить «0 компонентов» без сверки.

## Чем подтверждено

2026-10-07, `tests/test_dump.py` на реальной схеме: пакетный режим при
закрытом редакторе и живой при открытом человеком дали одинаковые
количества компонентов и цепей; mtime оригинала не изменился.
