# Установка

Клон, хук, автор и стоп-лист — skill-skill, `knowledge/40_СРЕДА/40-01`:

```bash
git clone https://github.com/RungeKut/Pcad-Skill.git "<папка скиллов>/pcad"
```

Корень набора — папка `SKILL.md`; переменные окружения для поиска набора
не нужны (`import sys; sys.path.insert(0, r"<корень>")`). Соседние наборы
`pkit` не использует. Правка `SKILL.md` подхватывается без перезапуска
агента (skill-skill, 40-01).

## Зависимости

* **P-CAD 2002** — `C:\Program Files (x86)\PCAD2002` (`Sch.exe`,
  `Dbx\Dbx32.dll`, `Dbx\Dbx32.h` — канонический API). Другая папка —
  переменная `PKIT_PCADROOT` (путь программы, а не набора).
* **.NET Framework 4 `csc.exe`** —
  `C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe`, есть в любой
  Windows; собирает `DbxHost.exe` x86 (30-01). Ставить ничего не нужно.
* **Python 3.11+ любой разрядности**; модулей сверх стандартной
  библиотеки не нужно. Прав администратора не нужно.

## Сборка DbxHost.exe

`tools/dbx-host/DbxHost.exe` не под git. `pkit` собирает его сам при
первом обращении (`pkit.env.host_exe()` зовёт `build.bat`); руками —
после правки `DbxHost.cs`:

```bat
tools\dbx-host\build.bat
```

То же без `.bat`:

```bat
C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe /nologo /platform:x86 /target:exe ^
  /out:tools\dbx-host\DbxHost.exe /r:System.Web.Extensions.dll tools\dbx-host\DbxHost.cs
```

`/platform:x86` обязателен: `Dbx32.dll` 32-битная (30-01).

## Проверка

```bash
python tools/check_docs.py                     # до «Расхождений нет»
python -c "import sys; sys.path.insert(0, '.'); import pkit as pk; print('pkit', pk.__version__, '|', pk.pcad_root())"
```

Схему дым-тест не открывает: Sch.exe может быть занят человеком (30-03).
Полный тест открывает Sch.exe на копии — **окно на столе человека**;
запускать, когда человек согласен или Sch.exe уже открыт им (тогда тест
читает живой редактор):

```bash
python tests/test_dump.py "<схема.SCH>" [--components N] [--nets N]
```

Путь к схеме и ожидания — аргументами: в набор они не попадают (40-02).
